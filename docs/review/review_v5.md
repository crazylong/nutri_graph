## 3. 同义种子放在字级模糊之前

`kg/textsim.py` 的包含关系：短名整段出现在长名里，得分是短长之比。0.62 挡得住猪脚/猪蹄（0.50），挡不住「多一个字」：

| 问句里的词 | 别名表里已有 | 得分 |
|---|---|---|
| 牛油果 | 牛油 | 0.67 |
| 猪脚 | 猪脚筋 | 0.67 |
| 猪脚 | 猪蹄 | 0.50 |
| 牛油果 | 鳄梨 | 0.00 |

L3 只扫 `dict_alias`（`fuzzy_lookup`）。种子文件解决的是字级过不了的那一对。它若排在 L3 后面，并且沿用原来的「这一层有命中就停止」，0.67 的那条会把种子盖住。测试库里如果只有猪蹄、没有猪脚筋，断言 1 仍然是绿的，生产上牛油果这一行会对到牛油。

层次改成：

1. L1 别名精确命中。
2. L2 `canonical_name` 精确点名。
3. L3.5 同义种子，再按 §13.4 的三步换成 `ING_`。有 id 的命中放进 `hits`，不因后面还有模糊结果就丢掉。
4. L3 仍用 0.62，只补充种子没有的「差一个字」。
5. L4 模型默认关。

种子命中和模糊命中可以同时出现，种子排在前面。没有种子、模糊也没有，才是 `not_found`。
